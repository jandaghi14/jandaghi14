## 🚀 Main Project

### [fastapi-mini-backend](https://github.com/jandaghi14/fastapi-mini-backend)
[![Run Tests](https://github.com/jandaghi14/fastapi-mini-backend/actions/workflows/test.yml/badge.svg?branch=main)](https://github.com/jandaghi14/fastapi-mini-backend/actions/workflows/test.yml)

A production-grade REST API built with FastAPI and PostgreSQL, covering all core backend fundamentals.

**Features:**
- 3-layer architecture: Presentation → Core → Infrastructure
- JWT authentication + bcrypt password hashing
- Role-based access control (admin / user)
- Full CRUD with soft delete and hard delete patterns
- Pagination, filtering, due date queries
- Eager loading with SQLAlchemy `joinedload` — N+1 prevention
- Alembic database migrations
- Structured logging (FileHandler + StreamHandler)
- Global exception handler
- 47 tests — all passing ✅
- Dockerised with docker-compose
- GitHub Actions CI/CD pipeline — tests run on every push to main
